# Test doubles

**Category:** Testing  
**Demo:** [test_doubles.typhon](test_doubles.typhon)  
**Wikipedia / ref:** [Test doubles](https://martinfowler.com/bliki/TestDouble.html)

## Intent

Dummy, Stub, Fake, Spy, Mock — five stand-ins for one port.

## Prompting an AI

**Say this:** “Show Dummy/Stub/Fake/Spy/Mock for a Mailer port used by Notifier.”

**Not this:** “Mock everything including values with no behavior.”

**Confusion to avoid:** Mock ≠ Fake.

## Run

```text
python -m transpiler run examples/patterns/testing/test_doubles.typhon
```
